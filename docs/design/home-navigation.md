# Android 三栏主页与个人资料

依据 2026-11-19 提供的两张会议截图，在 `android/app` 的 Compose 主线上实现。保留 Case File v2 的纸色、卡片、字体与原创角色。截图的绿色背景是会议文字载体，不是新的应用配色要求。

## 页面与行为

- 左：**巩固**。每个本机内容包一张独立档案卡。新练习进入已有 Classic 框架；移除主入口的五种框架选择。已有其他框架的未完成记录仍按原框架续学，不删除引擎或历史偏好。
- 中：**讲解**。首次启动默认页，书本图标放大。顶部直接选择 PDF，下面是本机资料和预生成示例。文件确认仍使用现有 Import 页面，明确没有上传服务，不伪装成已上传/解析。
- 右：**我的**。本机昵称（可编辑、保存、取消、留空回到默认名）、角色选择、资料数、已练知识点数、到期待复习数、前往巩固入口及本机数据说明。没有虚构账号、连胜天数、等级或云同步状态。
- 学习页隐藏底栏，通过返回回到原 Tab；主 Tab 保留各自滚动位置。返回键从“我的/巩固”回到讲解，再交给系统。
- Tab、昵称、角色写入本机偏好；导航详情通过 SavedStateHandle 恢复。PDF 只保存确认所需的 URI/名称/大小，不在 Bundle 保存文件内容。大段外部分享文字在进程消失后安全退回主页，需要重新分享。

## 讲解与学前摸底边界

当前内容包没有独立的核心术语字段。此增量以**已有章节主题**提供“知道 / 有点模糊 / 不知道”三档本机自评，也可直接继续；陌生或模糊的章节标记为建议重点阅读。新练习在首次阅读准备前先进入此页，旧进度可以直接续学。

讲解使用原内容包的 `goal`、`recap.points`，原文使用该章题目引用关联的 `SourceChunk`，不新增论文解析或模型调用。显示“有来源不等于人工验证”。自评按 packageId + contentVersion + levelId 保存；版本变化不会套用旧自评，也不删除旧选择。

这完成的是本地阅读准备与导航衔接，**不是**截图中最终的“核心术语抽取 → 用户知识水平判断 → 个性化 AI 讲解”。`docs/product/onboarding-and-focus.md` 的阅读地图与 focus 提案仍需对齐；不擅自改 contract 或后端。

## 统计口径与兼容

个人主页统计来自现有 PackageRepository、SessionStore、MasteryStore。预生成示例计入本机资料；只统计当前包中存在、attempts > 0 的知识点。到期待复习使用当前引擎条件：未 solid 且 dueAt <= 当前时间；不代表全部待学习内容。

旧列表仅凭 mastery key 存在就显示完成，答错也可能被误标。这次改为所有单元 `isSolid` 才显示“已巩固”；练过但未达到该条件显示“待巩固”。未完成会话优先显示进度。无法读取的包/记录显示重试提示，原文件不被修改或删除。

## 仍需 B / C 对齐

1. B：用户身份、昵称/头像的正式字段、登录和云同步能力；本机资料如何绑定账户与处理冲突。
2. B/C：独立术语的稳定 ID、显示名称、来源引用，术语/章节熟悉度、关注重点字段及内容版本变化后的映射方式。
3. B：自评如何影响讲解请求、响应是否标明个性化依据，跳过自评的默认行为，以及错误/重试/取消约定。
4. B：PDF 上传/生成任务成功后如何交付可校验内容包和独立文档档案；当前文件确认不会调用服务。
5. C：确认“单一经典玩法”的最终映射。当前采用已有 `FrameId.CLASSIC` 作为新入口，包内题型保持兼容；旧框架只用于续学。
6. C：审核真机渲染截图中的昵称卡、统计文案、角色选择和中央图标大小；术语级摸底的最终布局待内容字段确定。
