## Notes

- **Rename (claim 1):** Docs and market tables should say "Gemini Notebook (formerly NotebookLM)". Older articles and some current ones still use the old name.
- **Alibaba endpoints (claim 10):** The Model Studio docs now use workspace-specific hosts like `https://{WorkspaceId}.<region>.maas.aliyuncs.com/compatible-mode/v1`. They tell users to migrate off `dashscope.aliyuncs.com`. API keys are bound to the region they were created in. The same page lists the Beijing URL with `ap-southeast-1` in one place and `cn-beijing` in another. Check this in the console before you copy it.
- **Prompt requirement (claim 10):** Both DeepSeek and Qwen JSON object modes require the word "json" in the prompt.
- **Claim 7:** Unresolved. Don't write "`*.run.app` is blocked" as fact. A probe from inside China would settle it. Kinsta's page lists tools such as WebSitePulse, ViewDNS.info and Comparitech for this (https://kinsta.com/blog/great-firewall-of-china-google-cloud-platform/). I haven't run any of them.
- **Claim 8:** Adding the stated stages gives about 3 to 24 working days. That is my arithmetic and excludes the SMS verification step. Aliyun says it cannot speed up the authority's review.
- **Fetch blocks:** Quizlet and Kahoot help pages returned 403. Those rows rest on search-result snippets.
- **Undated pages:** Many vendor pages (Quizlet, Kahoot, Gizmo, Knowt, Anthropic, Gemini docs) show no date. They are accurate as of my fetch on 2026-11-19.
- **Third-party contradiction (claim 3):** pdfquiz.com says Kahoot cannot read a PDF (https://pdfquiz.com/blog/how-to-make-a-kahoot-from-a-pdf, index date about 2026-08). Kahoot's own AI tools page contradicts this, so I went with Kahoot's page.
- **Paper2Galgame release date (claim 12):** The Steam store says 9 Aug and a Steam announcement says 10 Aug. This is probably a time-zone difference, but I didn't confirm it.
